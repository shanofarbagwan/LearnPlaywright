# VS Code Keyboard Shortcuts for Windows

| Action                  | Shortcut          |
|-------------------------|-------------------|
| Single-line comment     | Ctrl + /          |
| Multi-line comment      | Shift + Alt + A   |
| JSDoc comment           | /** + Enter       |
| Cut line                | Ctrl + X          |
| Copy line               | Ctrl + C          |
| Paste                   | Ctrl + V          |
| Undo                    | Ctrl + Z          |
| Redo                    | Ctrl + Y          |
| Find                    | Ctrl + F          |
| Replace                 | Ctrl + H          |
| Save                    | Ctrl + S          |
| Open terminal           | Ctrl + `          |
| Command palette         | Ctrl + Shift + P  |
| Quick open file         | Ctrl + P          |
| Toggle sidebar          | Ctrl + B          |
| Zen mode                | Ctrl + K Z        |
| New file                | Ctrl + N          |
| Open file               | Ctrl + O          |
| Close editor            | Ctrl + W          |
| Split editor            | Ctrl + \          |
| Switch between editors  | Ctrl + Tab        |
| Go to line              | Ctrl + G          |
| Format document         | Shift + Alt + F   |
| Toggle word wrap        | Alt + Z           |
| Multi-cursor            | Alt + Click       |
| Select all occurrences   | Ctrl + Shift + L  |
| Rename symbol           | F2                |
| Go to definition        | F12               |
| Peek definition         | Alt + F12         |
| Find references         | Shift + F12       |
| Toggle breakpoint       | F9                |
| Start debugging         | F5                |
| Step over               | F10               |
| Step into               | F11               |
| Step out                | Shift + F11       |
| Stop debugging          | Shift + F5        |
